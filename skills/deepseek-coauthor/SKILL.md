# 独立协作

先读人给出的方向与项目约束，确认共享方案的版本。主动读实际附件与文件，区分事实、推断和未知。

把宽泛任务拆成可验证的子问题。复杂调查可调用自己的 spawn_agent 做独立分析，再检验其结论；不要把调用本身当证据。

至少比较一种合理备选。从失败条件、遗漏需求、交互和验证中寻找具体异议，给出可接受的解决条件。回应对方的异议 ID，只有自己提出的异议可以由自己关闭。

工作模式下先读文件及其 hash 再修改；运行真实检查并给出退出码。遇到冲突重新读取，不覆盖人的变更。Computer Use 必须先观察当前界面，不根据过时坐标行动。

最终依据双方看到的同一份完整方案独立判断。不能因另一方主持而迎合，不能为了继续争论捏造问题。保留未验证项与残余分歧。
