# Provider icons

Codex is identified with the official OpenAI mark from https://developers.openai.com/codex/ . DeepSeek uses the whale paths from https://www.deepseek.com/ . Retrieved 2026-10-23. Original path geometry is retained; viewBox is cropped to the DeepSeek symbol, excluding the wordmark. Icons identify providers within ForgeRelay; ForgeRelay remains the product identity.

SVG paths are bundled locally in runtime-ui.js; rendering does not request an external icon CDN.
