# Henry · v0.6.5 贡献说明

贡献者：Henry（GitHub：HenryYee726）
状态：实现与验证完成，v0.6.5 已发布；功能源码保留在本地，尚未推送至公开仓库。

## 问题发现与方案确认

在测试中发现：Codex 端能够联网搜索，而 DeepSeek 端缺少对应能力。

经排查，DeepSeek 的模型调用能够正常联网，但 ForgeRelay 没有为其提供专用的网页搜索与抓取工具。

进一步核实 DeepSeek 官方已提供 Search / Fetch API，可复用现有 DeepSeek API Key，无需用户额外申请第三方搜索密钥。

## 本次贡献

负责问题发现、测试反馈、方案确认及本地验收，推动完成以下功能：

- 接入 DeepSeek 官方网页搜索与网页抓取接口。
- 新增 web_search、web_fetch 工具，覆盖会谈、派工、子代理和任务控制中的 DeepSeek 调用链。
- 在模型实验室增加“联网搜索与网页读取”开关，同时提供工具目录过滤与服务端权限检查。
- 复用既有密钥和代理设置，不将密钥写入源码。
- 增加参数校验、超时与取消处理、响应大小限制、内容截断标记和错误反馈。
- 将网页结果作为不可信外部资料处理，保留实际工具调用记录及来源链接。
- 补充使用方式与独立计费说明。

## 测试与验证

- 新增 6 项联网功能专项测试。
- 自动化回归及补跑累计 264 项测试通过。
- 使用官方接口实测搜索与抓取，均成功返回结果。
- 验证界面开关的保存和刷新恢复。
- 完成本地 Windows 便携 EXE 构建与启动验收。
- 更新本机程序后，确认原有配置、会谈、任务及加密保存的 DeepSeek 密钥得到保留。
- 发布前将程序版本统一为 0.6.5，并通过 10 项针对联网、前端、桌面引擎和打包的复验。

发布附件仅包含 Windows 便携程序包和 SHA-256 校验文件，未上传本地源码包。功能源码尚未推送至公开仓库，本次 contribution 分支仅提交贡献说明文档。

搜索与抓取按 DeepSeek 官方规则单独计费，不应宣传为永久免费功能。
