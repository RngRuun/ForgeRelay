# ForgeRelay 0.6.8 解决方案与验证

日期：2026-10-29。源码和内部设计仅存放私有仓库；公开发行包为 Windows x64 免安装覆盖更新版。

## 已完成措施

- 普通会谈按独立角色延续原生 Codex 会话，只追加新状态；权限、模型/行为设置或上下文身份变化时建立新会话。独立表决继续隔离，不能读取另一角色的私有表决。
- 保留完整实质对话与工具证据索引。明确区分日志摘要和原文，支持通过工具读取已保存的完整返回或按行分页。
- 工具输出全文独立保存并校验哈希，界面展开时按需加载，避免把长文反复塞进页面实时状态。对旧版可能截断的记录给出明确提示，不编造缺失内容。
- 状态保存使用唯一临时文件与原子替换，对短暂 Windows 文件占用做有限重试；持久化持续失败时展示提示并重试，保留旧的完整文件，不把已成功的工具改判失败。
- 提供专用只读数值计算工具，支持标量、向量和基础样本统计。它不能访问文件、网络或执行任意脚本。空写入范围继续禁止任意命令，禁止子代理的合同同时在工具目录与执行入口生效。
- 连续相同权限拒绝会停止无进展循环，改变命令文字不能解除权限边界。
- 统一长工具与外层回合的执行生命周期；外层结束、取消或超时会取消对应的后台工具执行。工具桥不再固定在 240 秒提前结束。
- 计量基线缺失时保留成功回答，将用量标为未知并重建后续计量基线，不计零、不制造缓存命中数据。

## 验证

- 306 项自动测试通过，包含新增 15 项回归；覆盖真实 Windows 文件共享锁、原子保存失败保护、角色续接/隔离、权限过滤、完整输出与校验、无进展停止、计量未知及回合结束取消工具。
- 实际浏览器验证：20,036 字符工具全文可展开，实时重绘后保留；1440、768、390 像素下无页面横向溢出，三处主要导航保留，没有本地资源 HTTP 错误或 JavaScript 异常。
- Windows 发行构建通过；发布前额外核验实际原生续接与覆盖更新包，验证结果见后续验收记录。

## 使用与限制

退出旧版，解压新包后运行包内 Update-ForgeRelay.cmd，选择旧应用目录；不要只从压缩包中拖出更新器。保留会谈、配置、凭据和项目，更新器验证清单并备份旧程序。

不降低用户选择的模型或推理参数，不使用回答缓存冒充推理，不声称缓存命中率达到固定目标。专用计算采用双精度浮点，样本统计并非真实 LLM 实验或通用置信保证。旧版已丢失的输出尾部需要重新取证。


## 最终发行包验收

从准备公开上传的便携 ZIP 实际解出程序及其运行资源，校验清单、运行时、字节码、桌面资源与依赖一致；未发现可读后台核心模块、内部文档、用户数据或源码映射。使用实际便携程序在隔离目录从 0.6.7 覆盖升级到 0.6.8，五份用户数据/配置/凭据/项目哨兵文件保持逐字一致，旧程序备份存在。没有覆盖正在运行的用户应用。
