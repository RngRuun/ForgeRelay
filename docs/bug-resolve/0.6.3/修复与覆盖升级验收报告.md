## 补充修复

- DeepSeek 两条调用路径遵守设置中的超时，不再固定为 180 秒。
- 工具回路每完成一段即保留真实历史；后续网络失败或最终格式拒绝也不丢证据。
- 修改代理、密钥或模型时，旧检查不能回写为当前成功状态；非法模型 ID 不部分保存。
- 离页释放 SSE，返回恢复，修复连续切页后删除请求阻塞；新消息不抢图表位置。
- 处理窗口销毁/异步加载竞态和退出响应提前断开。
- 生产资源路由补齐 `human-directions.js`；正式服务前端依赖图回归涵盖所有入口及传递依赖。
- 独立加载恢复脚本在模块缺失时提供明确的重试入口。
- 源码启动不再寻找包外构建；自动准备依赖、Electron 和校验后的 Node，修正 CMD 换行兼容。
- 桌面拒绝复用旧版本/不兼容后台，防止覆盖更新后仍加载旧代码。

## 覆盖升级规则

1. 首次使用可直接解压并打开 `ForgeRelay.exe`。后续保留固定文件名。
2. 从 0.6.1 / 0.6.2 升级：先从托盘退出旧版本，将新 ZIP 解压到临时目录，运行 `Update-ForgeRelay.cmd`，选择原应用目录。
3. 更新器仅允许清单中固定的程序/说明文件。验证 SHA-256 和长度，先暂存和备份，再替换；中途失败按逆序回滚。
4. 旧版带版本号的 exe 同步更新，已有快捷方式迁移到固定入口。损坏包、路径越界、覆盖降级、运行中的目标应用会明确拒绝。
5. `ForgeRelay.config.json`、`data/`、项目、附件与 `deepseek-key.encrypted` 不覆盖。默认 `%APPDATA%/ForgeRelay` 用户目录不随程序替换。
6. 同一 Windows 用户的加密凭据沿用原生存储。仅驻留旧进程内存而未选择记住的密钥，无法通过文件更新凭空恢复。
7. 覆盖更新不会自动恢复模型推理或强迫未参与模型发言。

已使用固定入口的版本，可以在退出应用后直接将 ZIP 内容覆盖到原目录，也可以继续使用更新器取得备份与回滚保护。

## 性能与适用范围

优化不修改供应商模型质量参数，也不降低用户设定的互审轮数、异议关闭权限、证据要求和独立投票。缓存指标只读供应商实际返回的命中/未命中 tokens；冷启动、供应商缓存保留时间和新增上下文都会影响比例，不能承诺所有请求达到 99%。

支持 Windows x64 免安装；普通用户可在有写权限的应用目录更新。源码需要 Node.js 22.19+；部分文档解析、浏览器/桌面工具仍需原有外部依赖。自动检查覆盖所列场景，不证明所有未知环境不存在缺陷。
