# 0.6.7 执行连续性与上下文解决方案

日期：2026-10-29。

## 修复措施

- 移除按固定字符数自动丢弃会谈、派工及工作台历史的路径。已经返回的完整证据继续保留，独立表决的历史隔离仍然有效。
- DeepSeek Flash/Pro 采用当前官方 1M token 窗口进行输入预算估算，预留系统、图像和输出空间，并用实际 usage 校准；未知自定义模型采用保守回退。字符数不再冒充 token 数。估算不是精确分词结果；服务商返回仍是最终依据。
- 接近输入容量时明确提示并保留历史，不静默清空证据，也不原样自动反复付费重试。当前没有实现无损的无限上下文；超过模型能力仍需按证据范围拆分任务。
- 移除 8/10 轮工具回路、4 次派工和 210 秒派工总时长的固定限制。任务仍受用户取消、用户设置的实际预算、单次网络超时与真实权限约束。
- 同一只读工具连续三轮返回完全相同的结果时停止无进展循环，保留结果并要求改变方法；不将所有长任务都视为失败。正常取得新证据的长回路继续运行。
- 新增原合同续办入口：主持方核对当前人的要求、合同范围、验收项和权限仍相容后，按当前方向版本续办，保留原 ID、历次尝试和退回记录，旧验收不自动沿用。项目已改变、版本不符或运行中的合同不能据此越权续办。
- 对 JSON 字符串中的裸控制字符进行本地转义恢复，保留原字符串含义；其他非法结构仍报错，不编造字段、证据或表决，不为格式问题重新执行已完成工具。
- 附件文本可完整读取或按行分页。纯附件调查只有在完整原文仍可见、附件实际哈希未变时，才沿用同合同已经取得的取证，避免机械重读。
- 明确工具日志仅为摘要，不能将日志截断误认为附件原文不可读取。联网搜索与网页读取继续保留。

## 发布与限制

源码 ZIP 仅发布到私有 ForgeRelay-Private 的 Release；公共 ForgeRelay Release 只包含免安装覆盖更新包与校验文件。公共分支仅提交报告，不提交新源码。

Codex 的模型窗口由本机 CLI 与所选模型管理，本应用不虚构其固定容量。不承诺所有任务成功、不承诺每次缓存命中 99%，也没有 GPU 能耗遥测结果。
